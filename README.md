# 📝 Solicitud de Crédito — PDF por WhatsApp

Aplicación web para generar solicitudes de crédito en **formato PDF** y enviarlas por **WhatsApp**.

## 🚀 Funcionalidades

- Formulario completo con datos del cliente, aval, ingresos, gastos y crédito.
- Cálculos automáticos de totales y capacidad de pago.
- Vista previa del PDF en tiempo real.
- Generación de PDF con **diseño a color** en tamaño carta.
- Envío directo por WhatsApp al número **+52 249 110 3620**.
- Descarga del PDF e impresión.
